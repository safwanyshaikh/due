## Guardrails added

`src/lib/__tests__/guardrails.test.ts` now fails if any file under `src/` (excluding `__tests__`) or
`index.html`:

- imports a module whose path contains `sample`, `demo`, `mock` or `fixture`;
- contains "(demo)", "Demo data", "Demo only", "Demo:", "sample data", `buildSampleData`, `sampleRelay`,
  `removeSampleData`, `buildCatalog`, `offers/catalog`, `snapshotAdapter`, "research snapshot)" or
  "Check sources again";
- mentions `isSample` anywhere except `src/lib/migrate.ts`;
- still has `sample.ts`, `offers/catalog.ts` or `offers/refresh.ts`;
- makes a network call from any file other than `src/lib/offers/api.ts`, or that client calls an absolute
  URL, uses a mutating method, or sends credentials.
